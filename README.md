# Olist Data Warehouse

Data Management project (Sapienza, a.y. 2025/2026, Option 2 — Data Warehousing).
Paolo Pagliarini, 2063987.

A data warehouse built on the [Olist Brazilian E-Commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
(~100k orders, 2016–2018, nine CSV files): ETL in SQL on PostgreSQL through a **reconciled layer**, a
**DFM** conceptual model, a **star schema with two fact tables** on conformed dimensions, and seven **OLAP
sessions** on delivery performance, reviews, shipping costs, seasonality and seller concentration.

## How to run

Prerequisites: PostgreSQL 14+ running locally, Python 3.12+ with [`uv`](https://docs.astral.sh/uv/),
a Kaggle account for the dataset.

```bash
uv sync                          # python deps (psycopg for the staging load, matplotlib for charts)
scripts/download_data.sh         # Olist CSV files -> data/raw/   (needs KAGGLE_API_TOKEN or ~/.kaggle/access_token)
scripts/run_all.sh               # rebuilds everything: schemas -> staging -> reconciled -> star schema -> checks (~10-15 s)
psql -d olist_dw -f sql/olap/05_late_delivery_vs_review.sql     # run one OLAP session
```

`run_all.sh` drops and recreates the three schemas, so it can be run as many times as needed. The database
name defaults to `olist_dw` (override with `PGDATABASE`).

Diagrams, charts and slides are generated from the built database:

```bash
docs/dfm/build.sh                # DFM and star schema SVG (the star schema is read from the dw catalog)
uv run scripts/make_charts.py    # the three charts used in the slides
docs/slides/build.sh             # slides -> docs/slides/build/olist-dw-slides.pdf (headless Chrome)
```

## Repository layout

```
data/raw/                 the nine CSV files (not versioned, ~120 MB)
scripts/
  download_data.sh        Kaggle download
  load_staging.py         CSV -> staging.* (COPY, all columns TEXT)
  run_all.sh              full rebuild, in order
  make_charts.py          charts for the slides (matplotlib, queries on the star schema)
sql/
  00_schemas.sql          staging / reconciled / dw
  20..27_reconciled_*.sql the reconciled layer: lookups, geolocation, customers & sellers, products,
                          orders, order items, payments, reviews
  30_dw_dimensions.sql    dim_date, dim_customer, dim_seller, dim_product, dim_payment_type, dim_order_status
  40_dw_facts.sql         fact_order_item (line grain), fact_order (order grain)
  50_dw_materialized_views.sql
  60_quality_checks.sql   row counts, totals, consistency — fails the build if violated
  olap/01..07_*.sql       the OLAP sessions
demo/                     SQL files and psql settings for the live demo
docs/
  DESIGN.md  OLAP.md      design notes, analyses
  DEMO.md                 live demo script
  STUDY.md                study guide (Italian)
  dfm/                    diagrams + generator
  slides/                 presentation (index.html, charts in img/, build.sh)
```
