# Olist Data Warehouse

Data Management project (Sapienza, a.y. 2025/2026, Option 2) — a data warehouse built on the
[Olist Brazilian E-Commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce):
ETL in SQL on PostgreSQL (staging → reconciled → data warehouse), DFM conceptual model,
star schema with two fact tables, OLAP analyses.

Work in progress. See `docs/` for design notes once available.
